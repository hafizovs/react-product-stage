# Product stage

Interactive 3D product viewer — React Three Fiber, drei, Zustand.

## Scripts

```bash
pnpm install
pnpm dev          # http://localhost:5009
pnpm check
pnpm build
```

## Manual demo

1. Drag to orbit the product.
2. Change color via picker or swatch; switch shape.
3. Toggle studio / warehouse environment presets.
