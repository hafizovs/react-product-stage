# Product stage

## About

Interactive 3D product viewer built with React Three Fiber, drei, and Zustand. The mesh can be orbited, recolored from a picker or swatches, and switched to another shape. Environment presets are studio and warehouse.

## Capabilities

- Orbit controls
- Color picker and swatches
- Shape switch
- Studio and warehouse environment presets

## Functionality

- Drag to orbit the product
- Change color with the picker or a swatch, and switch shape
- Toggle the studio and warehouse presets

Interactive 3D product viewer — React Three Fiber, drei, Zustand.

## Responsive layout

Full adaptive layout for phone (~375px) and tablet (~768px): readable typography and spacing, no page-level horizontal scroll, and touch-friendly controls. The desktop visual language is preserved.

## Scripts

```bash
pnpm install

pnpm check
pnpm build
```
